# Golf Trip App

Database-ready golf trip tournament app with admin setup, player scorecards, scorecard review, and computed leaderboards.

## Current State

This branch is the shared full-app version with Supabase Auth, Postgres-backed trips, player scorecards, admin review, and Vercel deployment support.

The holiday/offline app lives on the older branch and is not changed by this branch.

## Local Preview

```bash
npm run serve
```

Open `http://localhost:8080`.

## Checks

```bash
npm run check
```
